# Contributing

Contributions, discussions, and improvements are welcome.

## Process

```
Fork
 |
Feature Branch
 |
Commit
 |
PR
 |
Review
 |
Merge
```

## Branch Naming

```
feature/description
fix/description
docs/description
refactor/description
```

## Commit Messages

Follow conventional commits:

```
feat: add radar engine v2
fix: correct funding trace filter
docs: update API reference
refactor: extract graph interface
test: add risk engine unit tests
```

## Pull Request Checklist

Before submitting a PR, ensure:

- [ ] Code follows project style
- [ ] Tests pass locally
- [ ] Documentation updated if needed
- [ ] No secrets or credentials committed
- [ ] Lint and format checks pass

## Quality Gates

Every PR is checked for:

- Code formatting
- Linting
- Unit tests
- Integration tests
- Security scan
- Dependency scan
- License check
- Documentation validation
