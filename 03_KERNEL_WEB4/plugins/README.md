# Plugins

Data provider plugins for the WEB4 Engine.

## Planned Plugins

- `solscan/` — Solscan API integration
- `helius/` — Helius RPC and API
- `birdeye/` — Birdeye market data
- `debank/` — DeBank portfolio data
- `chainbase/` — Chainbase blockchain data
- `dexscreener/` — DEX Screener market data

## Plugin Interface

Each plugin implements a standard interface for data ingestion.
