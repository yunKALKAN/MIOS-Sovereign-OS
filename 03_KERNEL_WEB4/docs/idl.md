# IDL (Interface Definition Language)

## Overview

The IDL is auto-generated by Anchor from the smart contract source code.

## Generation

```bash
anchor build
```

The IDL is output to `target/idl/mzc_web4.json`.

## Usage

The IDL is used by:
- TypeScript SDK for client-side interaction
- Python SDK for off-chain service integration
- Auto-generated documentation
